# Shopping List — Lecture 2

SwiftUI project implementing the Lecture 2 assignment:
- `@EnvironmentObject` for the user name
- `@State` + `@Binding` for balance visibility
- `ObservableObject` + `@StateObject` for wallet/transactions
- `@ViewBuilder` reusable `CardContainer`
- `@State` dark mode toggle

Open `ShoppingList.xcodeproj` in Xcode and run on an iOS Simulator.
